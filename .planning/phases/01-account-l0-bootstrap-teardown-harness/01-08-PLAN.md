<objective>
Complete the sweep: the remaining network and log orphan classes, the tag layer, the global pass, and
the three-tier region scope — then record which scopes actually ran.

Purpose: the classes in this plan are where a sweep becomes noisy and therefore ignored. The default
security group is the single largest false-positive generator, producing one permanent phantom per
VPC per region on an account that has never been touched. Service-linked IAM roles do the same thing
in the global pass. Log groups resist name-based filtering entirely, because the reserved prefix
contains both this project's own groups and unrelated ones. Each of these is solved by the baseline
allowlist rather than by a heuristic, which is exactly why the baseline ran before anything was
provisioned.

The region tiers exist for a different reason: a region-only sweep misses the stray-region orphan
left by a mis-targeted console session, and a full all-regions enumeration costs a minute on every
teardown. Restricting the third tier to five expensive types buys the money-losing cases for a
handful of free calls.

Output: all nine required classes wired, the tag layer paginating correctly, three scopes in one
pass, and a report that distinguishes "found nothing" from "never checked".

Ordering: this plan runs after 01-07 rather than beside it, and the edge is load-bearing in both
directions. 01-07 writes two permanent IAM roles into the live account; this plan's task 3 runs a
live `make verify-teardown` against that same account and asserts the clean exit code. Their
`files_modified` sets do not intersect, so the wave overlap guard cannot see the coupling — the
dependency edge is the only thing that expresses it. Running this plan first would make that
assertion pass against an account where the roles do not yet exist, which is precisely the ordering
that hides a broken IAM immortality path until the hard gate in 01-09 fails. Running it second turns
the same assertion into a real test of the layer-tag lookup this plan adds.
</objective>
