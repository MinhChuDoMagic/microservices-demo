<objective>
Build the cost guardrails into the bootstrap layer: one SNS topic with a correct resource policy,
two budgets, and an anomaly monitor — plus the human steps that turn a green apply into a live alert
path.

Purpose: three separate silent-failure modes converge on this one small set of resources. A
default-policy SNS topic drops both publishing service principals with no error anywhere. An email
subscription applies green while remaining inert until a human clicks. And the anomaly detector
cannot meet the roadmap's within-one-day criterion on an empty account, because it needs ten days of
per-service history that does not exist. Each of these produces a phase that passes with its
alerting doing nothing, which is worse than having no alerting, because it is believed.

Output: a guardrail set whose live configuration is asserted from the AWS API rather than from
`terraform apply`, with a deterministic daily tripwire covering the anomaly detector's cold start.
</objective>
