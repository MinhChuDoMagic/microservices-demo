zero AWS credentials.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| working tree -> git remote | Account-identifying values (AWS account ID in generated `backend.hcl` and in local state, `alert_email` in tfvars) cross here if gitignore coverage is wrong. |
| operator shell -> AWS account | `make doctor` is the only thing standing between an ambiguous shell environment and an apply into the wrong AWS account. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-01 | Information Disclosure | `.gitignore` / working tree | high | mitigate | Task 1 lands `.gitignore` before any command can write local state; task 3's doctor check 7 re-asserts coverage of `backend.hcl`, `*.tfstate` and `*.tfvars` on every run, and the acceptance criteria assert `git check-ignore` positively and negatively. |
| T-1-02 | Spoofing | operator AWS credentials | high | mitigate | `make doctor` compares `sts get-caller-identity` against the gitignored `.aws-account-id` pin and fails with both IDs printed; every AWS-touching target declares `doctor` as a prerequisite. |
| T-1-03 | Tampering | version pins | medium | mitigate | Exact equality pins in every `versions.tf` plus the doctor cross-check that `.terraform-version` and every layer's `required_version` agree; a mismatched binary is rejected before it can rewrite state. |
| T-1-04 | Elevation of Privilege | Terraform providers | low | accept | No `kubernetes`/`helm` provider is declared and no credentials are used by any target in this plan; the layers are resource-free. Accepted because this plan provisions nothing. |
| T-1-SC | Tampering | tool installation (`bats-core`, `shellcheck`) | low | accept | No npm/pip/cargo install task exists in this phase; both tools are installed from the operator's system package manager outside the repository, so no package-manager manifest enters version control. Recorded rather than gated. |
</threat_model>
