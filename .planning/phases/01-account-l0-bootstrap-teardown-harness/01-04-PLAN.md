<objective>
The tracer slice for this phase: one end-to-end path through every layer Phase 1 touches — Makefile
to Terraform to the live AWS account to the teardown sweep and back to an exit code — proven before
any expansion task widens it.

Purpose: this phase's architecture has three seams that are cheap to get wrong and expensive to
discover late. The bootstrap chicken-and-egg (a layer that creates the bucket holding its own state).
The lock evidence (a `.tflock` that exists only during an apply). And the sweep's three-way exit
contract (a verifier that must distinguish "the account is dirty" from "I could not answer"). Wiring
one thin path through all three on the executor's best early-context tokens catches an architectural
dead end after one commit instead of after ten.

This plan also carries the phase-level ledgers: the spec-less probe edge accounting, the flagged
assumptions, the assumption-delta ruling, the multi-source coverage audit, and the complete
phase artifact table.

Output: `make bootstrap` lands state in a versioned S3 bucket with observable lock lifecycle,
`scripts/verify-teardown.sh` exists and exits 0 against the resulting account, and the account's
pre-existing survivors are recorded on a reviewed allowlist.
</objective>
