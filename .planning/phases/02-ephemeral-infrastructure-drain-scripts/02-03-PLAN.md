<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Karpenter controller identity → AWS IAM | Pod Identity grants the controller AWS permissions to provision node capacity. |
| EventBridge → SQS | Interruption events are delivered to a project-owned queue. |
| Terraform L1 → EKS/AWS resources | L1 owns AWS resources but not Kubernetes objects. |

ASVS L1 is applied; any high-severity threat blocks plan completion.

| T-02-10 | T — Tampering | Interruption queue and EventBridge wiring | medium | mitigate | Terraform owns queue, rule, target, and resource policy; local validation and source contracts verify the complete path. |

</threat_model>
