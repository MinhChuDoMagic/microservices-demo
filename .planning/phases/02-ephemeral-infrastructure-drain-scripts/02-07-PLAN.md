<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator manual command → Cloud Nuke | A broad destructive binary receives account, region, type, and tag filters. |
| Cloud Nuke config → AWS resource discovery | Filter semantics and cascades vary by resource type. |
| Normal teardown → recovery utility | A drain failure must not implicitly invoke a separate destructive fallback. |

ASVS L1 is applied; any high-severity threat blocks plan completion.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-25 | T — Tampering | Recovery resource filters | high | mitigate | Positive Project-tag include, explicit tested type/region list, same-type untagged control, and no VPC type. |
| T-02-26 | E — Elevation of Privilege | Cloud Nuke binary/config | high | mitigate | Exact official release/checksum validation and expected-account preflight before preview or delete. |
| T-02-27 | D — Denial of Service | Untagged residual resources | medium | mitigate | Report uncovered resources and retain explicit manual handling; never widen the deletion boundary. |
| T-02-28 | T — Tampering | Preview-to-execution target drift | high | mitigate | Reuse the exact immutable config/region/type argument vector and assert parity in tests. |
</threat_model>
